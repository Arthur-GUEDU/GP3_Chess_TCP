# **Chess-Multi**

This project aimed to integrate networking into a chess game.

## 📝 Informations

We were 2 and had 2 weeks at Isart Digital to add multiplayer with networking to a chess game base project provided. This would allow a player on a first computer to create a server and host a chess game, and a second player on another computer to connect to the first player's server as client and play against him.

This project was made using Unity 6000.0.58f2 and C#.
